# 00 — Contexto del proyecto

Pegar este bloque al inicio de cualquier sesión nueva antes de ejecutar una etapa.

```
CONTEXTO DEL PROYECTO (referencia, no ejecutar nada todavía)

App Android "SwipeClean": limpieza de galería por gestos. Deslizar izquierda
marca la foto para eliminar, deslizar derecha la conserva. El borrado se hace
en lote al final de la sesión.

Stack: Kotlin, Jetpack Compose + Material 3, minSdk 26 / targetSdk 35,
MVVM + Clean Architecture (data / domain / ui), Hilt, Coroutines + Flow,
Coil 3, Room, MediaStore API.

Package base: com.swipeclean.app
Strings en español, en strings.xml.
```
